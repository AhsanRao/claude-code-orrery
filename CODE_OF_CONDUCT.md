# Code of Conduct

Everyone interacting in this project's codebases, issue trackers and discussions is expected to:

- Be respectful and constructive. Critique code, not people.
- Assume good intent; ask before judging.
- Keep discussions on topic and free of harassment of any kind.

Unacceptable behaviour may result in removal from the project spaces at the maintainers' discretion. Report concerns privately to the maintainers via the email on the GitHub profile.

This document is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
